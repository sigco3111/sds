개인정보

계정 없이 플레이할 수 있습니다

이 한국어판 Sheepdog Sim은 솔로 플레이 전용입니다. 온라인 기록과 멀티플레이 서버에 연결하지 않으며, 어떤 개인 정보도 서버로 보내지 않습니다.

로컬 데이터

게임은 환경 설정, 조작 배정, 개인 최고 기록, 개와 양의 이름을 브라우저 로컬 저장소에 저장합니다. 사이트 데이터를 지우면 이 정보가 모두 삭제됩니다.

호스팅

이 한국어판은 GitHub Pages에서 제공됩니다. GitHub과 관련 네트워크 사업자는 보안과 전송을 위해 IP 주소, 사용자 에이전트, 요청 경로, 시각 같은 표준 요청 정보를 처리할 수 있습니다.

소스와 문의

클라이언트 소스는 공개되어 있습니다. 문의는 소스 저장소에 남겨 주세요.
